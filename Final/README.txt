DeliveryService — учебный демонстрационный проект

Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в современном браузере (Chrome, Edge, Firefox).
3. В правом верхнем углу переключите роль на «Администратор».
4. Откройте раздел «Заказы».
5. Для нужного заказа выберите новый статус и нажмите «Сохранить».

Реализованная функция (МДК 05.02, задание 2)
Администратор может устанавливать для заказа статусы:
- Новый;
- Назначен курьер;
- В доставке;
- Доставлен;
- Отменён.

Изменения сохраняются в localStorage браузера. При обновлении страницы данные остаются.
При назначении статуса «Назначен курьер» демонстрационный курьер назначается автоматически.
При возврате к статусу «Новый» или отмене заказа назначение курьера очищается.
Для каждого изменения формируется запись истории статуса в объекте заказа.

Важно
Это учебный клиентский прототип. Переключатель ролей демонстрационный и не является
настоящей авторизацией или защитой доступа. localStorage доступен только в том браузере,
в котором открыт проект; данные не синхронизируются между устройствами.
Сервер, SQLite и Open Server для запуска этой версии не требуются.

Файлы
