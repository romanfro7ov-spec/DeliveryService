DeliveryService — рабочий HTML-прототип

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. Откройте index.html двойным щелчком в браузере (Chrome, Edge или Firefox).
3. Переключайте роли в правом верхнем углу: Заказчик / Курьер / Администратор.

ЧТО РАБОТАЕТ
- Навигация между разделами.
- Создание заказа через форму.
- Просмотр заказов и поиск/фильтр по статусу.
- Кабинет курьера: принять заказ, начать доставку, отметить доставленным.
- Кабинет администратора: последовательно менять статус и смотреть детали.
- Экспорт списка заказов в CSV.
- Данные сохраняются в localStorage этого браузера после перезагрузки.

БАЗА ДАННЫХ
database.sql — SQL-схема SQLite с таблицами клиентов, курьеров, сотрудников,
заказов, назначений курьеров и истории статусов. Статический HTML не подключается
к SQLite напрямую: текущий демонстрационный сайт сохраняет данные в localStorage.
Для реального многопользовательского режима потребуется серверная часть и API.
